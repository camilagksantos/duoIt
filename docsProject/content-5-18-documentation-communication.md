# Conteúdo: 5.18 Vocabulário de documentação e comunicação

Regras usadas:
- Cada palavra aparece em um só grupo.
- As frases usam as estruturas até o 17º lugar da ordem.
- Os grupos seguem o plano: documentação (A), pedidos e avisos (B) e canais e chamadas (C).

| Termo | Significado no contexto | Exemplo |
|-------|-------------------------|---------|

| architecture | arquitetura | The architecture has three layers. |

| FAQ | perguntas frequentes | The FAQ answers the common questions. |
| API reference | referência da API | The API reference lists every endpoint. |

| diagram | diagrama | The diagram shows the data flow. |
