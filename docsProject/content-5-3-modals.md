# Conteúdo: 5.3 Modais de sugestão e obrigação

Status: rascunho para revisão. Ainda não foi carregado no banco.

Regras usadas:
- Cada palavra aparece em um só grupo.
- Os modais deste módulo aparecem nas frases. Não usar present perfect (5.4) nem voz passiva (5.6).
- O significado é o usado na frase.

## Grupo A: Sugestões

| Termo | Significado no contexto | Exemplo |
|-------|-------------------------|---------|
| should | deveria | You should add a test. |
| could | poderia | We could simplify this part. |
| shouldn't | não deveria | You shouldn't push to main. |
| should I | devo | Should I update the docs? |
| should we | devemos | Should we add a comment? |
| could we | poderíamos | Could we move the meeting? |
| could you | você poderia | Could you check my change? |
| let's | vamos | Let's review the PR together. |
| let's not | vamos não | Let's not deploy today. |
| shall we | vamos? | Shall we start? |
| why don't we | por que não | Why don't we try another cache? |
| what if | e se | What if we use a queue? |
| how about | que tal | How about a short break? |
| how should I | como devo | How should I name this variable? |
| you should | você deveria | You should write a test first. |
| you could | você poderia | You could check the docs first. |
| we should | deveríamos | We should talk to the client. |
| we shouldn't | não deveríamos | We shouldn't skip the tests. |
| we could | nós poderíamos | We could use a script. |
| they should | eles deveriam | They should answer the email. |
| I could | eu poderia | I could help you after lunch. |
| should be | deveria estar | It should be ready today. |

## Grupo B: Obrigação e necessidade

| Termo | Significado no contexto | Exemplo |
|-------|-------------------------|---------|
| must | precisar (obrigação forte) | You must log in first. |
| have to | ter que | I have to finish this today. |
| need to | precisar | We need to fix the bug. |
| needs to | precisar (com ele ou ela) | The app needs to restart. |
| has to | ter que (com ele ou ela) | She has to approve it. |
| don't have to | não precisar | You don't have to attend. |
| don't need to | não precisar | You don't need to reply today. |
| needn't | não precisa | You needn't reply today. |
| mustn't | não pode | You mustn't share the password. |
| must not | não deve (proibição) | You must not commit secrets. |
| must be | deve ser | It must be ready by Friday. |
| are required to | são obrigados a | We are required to test everything. |
| supposed to | deveria (combinado) | I'm supposed to call the client. |
| ought to | deveria (mais forte) | We ought to document this. |
| is not allowed to | não é permitido | We're not allowed to deploy on Friday. |
| it's necessary to | é necessário | It's necessary to back up the data. |
| it's essential to | é essencial | It's essential to test the login. |
| you need | você precisa | You need a VPN to connect. |
| they need to | eles precisam | They need to restart the server. |
| I need | eu preciso | I need more time. |
