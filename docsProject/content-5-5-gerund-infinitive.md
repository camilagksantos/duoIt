# Conteúdo: 5.5 Gerúndio e infinitivo

Status: rascunho para revisão. Ainda não foi carregado no banco.

Regras usadas:
- Cada palavra aparece em um só grupo.
- As frases usam gerúndio e infinitivo, além das estruturas até o 10º lugar da ordem. Não usar voz passiva (5.6) nem phrasal verbs (5.14).

## Grupo A: Verbos seguidos de gerúndio

| Termo | Significado no contexto | Exemplo |
|-------|-------------------------|---------|
| avoid | evitar | I avoid merging on Fridays. |
| consider | considerar | We're considering using a cache. |
| suggest | sugerir | I suggest adding a test. |
| recommend | recomendar | I recommend writing the docs first. |
| enjoy | gostar de | I enjoy working on the frontend. |
| mind | importar-se com | Do you mind waiting a minute? |
| practice | praticar | I practice coding every night. |
| deny | negar | He denied breaking the build. |
| admit | admitir | I admit making a mistake. |
| imagine | imaginar | I can't imagine working without tests. |
| risk | arriscar | We risk losing data if we delay. |
| quit | parar (um hábito) | I quit working on Sundays. |
| delay | atrasar | The bug delayed the release. |
| miss | perder (algo) | I missed the call yesterday. |
| dislike | não gostar de | I dislike debugging in production. |
| appreciate | agradecer por | I appreciate you helping me. |
| keep on | continuar | Keep on testing the login. |
| give up | desistir de | I gave up writing that script. |
| finish | terminar | I finished writing the tests. |
| postpone | adiar | We postponed making the decision. |
| enjoy coding | gostar de programar | I enjoy coding in the morning. |
| suggest adding | sugerir adicionar | I suggest adding a cache. |
