# Conteúdo: 5.8 Discurso indireto e conectores

Status: rascunho para revisão. Ainda não foi carregado no banco.

Regras usadas:
- Cada palavra aparece em um só grupo.
- As frases usam discurso indireto e conectores, além de todas as estruturas anteriores (este é o último módulo da ordem).
- Os verbos de relato são os do grupo A. Os conectores são os dos grupos B a D.

## Grupo A: Verbos de relato

| Termo | Significado no contexto | Exemplo |
|-------|-------------------------|---------|
| said | disse | The lead said the release is on Friday. |
| asked | perguntou | The client asked for a demo. |
| mentioned | mencionou | She mentioned a bug in the login. |
| confirmed | confirmou | He confirmed the meeting at ten. |
| replied | respondeu | The team replied within an hour. |
| claimed | afirmou | The vendor claimed the fix was ready. |
| insisted | insistiu | The client insisted on a demo today. |
| warned | avisou | The lead warned us about the deadline. |
| wondered | se perguntou | I wondered if the API was down. |
| noted | observou | The reviewer noted a missing test. |
| said that | disse que | She said that the build was green. |
| asked if | perguntou se | He asked if the tests passed. |
| asked whether | perguntou se | The client asked whether we could move the date. |
| mentioned that | mencionou que | He mentioned that the server was slow. |
| confirmed that | confirmou que | She confirmed that the release is on track. |
| replied that | respondeu que | The team replied that they need more time. |
| claimed that | afirmou que | The vendor claimed that the API is fast. |
| warned that | avisou que | The lead warned that the release is risky. |
| insisted that | insistiu que | The client insisted that the demo is needed. |
| wondered if | se perguntou se | I wondered if the cache was stale. |

## Grupo B: Conectores de causa

| Termo | Significado no contexto | Exemplo |
|-------|-------------------------|---------|
| because | porque | We delayed the release because of a bug. |
| since | já que, como | Since the tests failed, we stopped the deploy. |
| due to | por causa de | The release was late due to a bug. |
| because of | por causa de | We're late because of the outage. |
| as | como (causa) | As the server was down, the page failed. |
| owing to | devido a | Owing to the delay, the demo moved. |
| thanks to | graças a | Thanks to the team, we shipped on time. |
| as a result of | como resultado de | The bug was fixed as a result of the review. |
| given that | considerando que | Given that the tests pass, we can merge. |
| since it | já que isso | Since it's late, we'll review tomorrow. |
| because it | porque isso | Because it's broken, I rolled back. |
| due to the bug | por causa do bug | The release was delayed due to the bug. |
| because of the deadline | por causa do prazo | We worked late because of the deadline. |
| since we | já que nós | Since we're short on time, we'll cut the scope. |
| because we | porque nós | Because we didn't test it, it broke. |
| as they | como eles | As they were offline, we used the email. |
| on account of | por causa de | The demo was canceled on account of the outage. |
| because you | porque você | Because you reviewed it, we merged quickly. |
| as a consequence | como consequência | As a consequence, the sprint was longer. |
| so that the | de forma que | We cached it so that the page loads faster. |

## Grupo C: Conectores de contraste

| Termo | Significado no contexto | Exemplo |
|-------|-------------------------|---------|
| although | embora | Although the tests pass, the bug is still there. |
| however | porém | The code works. However, it's slow. |
| but | mas | The feature works, but it's slow. |
| though | embora | It works, though it's slow. |
| even though | mesmo que | Even though it's late, the team is happy. |
| despite | apesar de | Despite the bug, we shipped on time. |
| in spite of | apesar de | In spite of the delay, the client is happy. |
| nevertheless | mesmo assim | The test failed; nevertheless, we deployed. |
| nonetheless | mesmo assim | It's risky; nonetheless, we'll try it. |
| whereas | enquanto (contraste) | The frontend is fast, whereas the API is slow. |
| while | enquanto (contraste) | While the tests pass, the UI is broken. |
| on the contrary | pelo contrário | On the contrary, the bug is getting worse. |
| instead | em vez disso | Instead of coding, I read the docs. |
| even if | mesmo se | Even if it fails, we learn something. |
| despite the bug | apesar do bug | Despite the bug, the demo went well. |
| in spite of the bug | apesar do bug | In spite of the bug, the client was happy. |
| although it works | embora funcione | Although it works, I'd refactor it. |
