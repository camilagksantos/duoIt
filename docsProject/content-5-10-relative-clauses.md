# Conteúdo: 5.10 Orações relativas

Status: rascunho para revisão. Ainda não foi carregado no banco.

Regras usadas:
- Cada palavra aparece em um só grupo.
- As frases usam orações relativas, além das estruturas até o 15º lugar da ordem.
- Os termos são as expressões com o pronome relativo: "the developer who", "the bug that", "the place where".

## Grupo A: Pronomes relativos de pessoa

| Termo | Significado no contexto | Exemplo |
|-------|-------------------------|---------|
| those who | aqueles que | Those who merge late stay late. |
| the developer who | o desenvolvedor que | The developer who fixed the bug is on leave. |
| the person who | a pessoa que | The person who reviews the PR is Ana. |
| the engineer who | o engenheiro que | The engineer who built the API is here. |
| the designer who | o designer que | The designer who made the layout is new. |
| the client who | o cliente que | The client who asked for the demo is happy. |
| the tester who | o testador que | The tester who found the bug works with us. |
| the manager who | o gerente que | The manager who approved the budget is out. |
| the lead who | o líder que | The lead who planned the sprint left the team. |
| the team member who | o membro do time que | The team member who handles support is busy. |
| whom | a quem (formal) | The person whom we need is in a meeting. |
| the user whom | o usuário que (formal) | The user whom we contacted replied quickly. |
| whose | cujo, cuja | The developer whose laptop broke works from home. |
| the one whose | aquele cujo | The one whose PR was merged is me. |
| the team whose | o time cujo | The team whose tests failed is backend. |
| the person to whom | a pessoa a quem | The person to whom I sent the report is the lead. |
| the colleague who | o colega que | The colleague who helped me is in Portugal. |
| the customer who | o cliente que | The customer who reported the crash is happy now. |
| the developers who | os desenvolvedores que | The developers who joined this month are learning fast. |
| the people who | as pessoas que | The people who attend the stand-up are the team. |

## Grupo B: Relativas que definem coisas

| Termo | Significado no contexto | Exemplo |
|-------|-------------------------|---------|
| that | que (para coisas) | This is the function that validates the input. |
| whichever | qualquer que | Whichever branch you choose is fine. |
| the function that | a função que | The function that validates the input is slow. |
| the module that | o módulo que | The module that handles login is new. |
| the bug that | o bug que | The bug that crashed the app is fixed. |
| the file that | o arquivo que | The file that holds the config is in root. |
| the server which | o servidor que | The server which runs the API is down. |
| the query which | a consulta que | The query which fetches users is slow. |
| the button that | o botão que | The button that sends the form is broken. |
| the feature that | a funcionalidade que | The feature that we shipped is popular. |
| the error that | o erro que | The error that appears on login is new. |
| the report that | o relatório que | The report that I sent is outdated. |
| the test that | o teste que | The test that failed is flaky. |
| the library that | a biblioteca que | The library that we use is well known. |
| the tool which | a ferramenta que | The tool which we use for tests is free. |
| the change that | a mudança que | The change that broke the build was small. |
| the document which | o documento que | The document which explains the flow is old. |
| the code that | o código que | The code that runs at night is slow. |
| the table that | a tabela que | The table that stores logs is huge. |
| the thing that | a coisa que | That's the thing that worries me. |
| the part which | a parte que | The part which needs work is the search. |

## Grupo C: Relativas de lugar e tempo

| Termo | Significado no contexto | Exemplo |
|-------|-------------------------|---------|
| wherever | onde quer que | Wherever the team works, the tools are the same. |
| the place where | o lugar onde | The room where we meet has a big screen. |
| the page where | a página onde | The page where users log in is slow. |
| the place where I work | o lugar onde eu trabalho | This is the place where I work. |
| the environment where | o ambiente onde | The environment where the bug happens is staging. |
| the server where | o servidor onde | The server where the data lives is in Brazil. |
| in which | em que | This is the month in which we launch. |
| the day when | o dia em que | The day when we deployed was tense. |
| the time when | o momento em que | The time when the demo failed was awkward. |
| the week when | a semana em que | The week when we shipped was long. |
| the moment when | o momento em que | The moment when the build passed was great. |
| the sprint when | a sprint em que | The sprint when we added payments was hard. |
| the month when | o mês em que | The month when we hired was busy. |
| the year when | o ano em que | The year when we started was hard. |
| the place where we | o lugar onde nós | The place where we deploy is locked. |
| the moment when we | o momento em que nós | The moment when we merged, everything broke. |
| the meeting where | a reunião em que | The meeting where we decided it was short. |
| the document where | o documento onde | The document where we keep the notes is in the wiki. |
| the tool where | a ferramenta onde | The tool where I track tasks is the board. |
| the way in which | o jeito como | This is the way in which we test. |
