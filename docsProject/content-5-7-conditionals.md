# Conteúdo: 5.7 Condicionais

Status: rascunho para revisão. Ainda não foi carregado no banco.

Regras usadas:
- Cada palavra aparece em um só grupo.
- As frases usam condicionais zero, primeiro e segundo, além das estruturas até o 16º lugar da ordem.
- "will" e "would" aparecem nas frases das condicionais, como parte da estrutura.

## Grupo A: Condicional zero (fatos e processos)

| Termo | Significado no contexto | Exemplo |
|-------|-------------------------|---------|
| if | se | If the build fails, the team gets an alert. |
| whenever | sempre que | Whenever I deploy, I check the logs. |
| unless | a menos que | Unless the tests pass, we don't release. |
| as long as | desde que | As long as the tests pass, the build is green. |
| if it's green | se estiver verde | If it's green, we can merge. |
| if the server is down | se o servidor cair | If the server is down, the site stops. |
| if I forget | se eu esquecer | If I forget to commit, the work is lost. |
| if you need help | se você precisar de ajuda | If you need help, ping the team. |
| if the test fails | se o teste falhar | If the test fails, the build stops. |
| if the data is wrong | se os dados estiverem errados | If the data is wrong, the report breaks. |
| whenever there's a bug | sempre que houver um bug | Whenever there's a bug, we write a test. |
| if the API is slow | se a API estiver lenta | If the API is slow, the page loads slowly. |
| if we deploy on Friday | se publicarmos na sexta | If we deploy on Friday, the team works late. |
| if I don't know | se eu não sei | If I don't know, I ask. |
| unless we test | a menos que testemos | Unless we test it, we won't know. |
| when the cache is full | quando o cache está cheio | When the cache is full, it slows down. |
| if the lint fails | se o lint falhar | If the lint fails, the commit is blocked. |
| whenever the team meets | sempre que o time se reúne | Whenever the team meets, we plan the sprint. |
| if the config changes | se a configuração mudar | If the config changes, we restart the server. |
| when I'm stuck | quando eu travo | When I'm stuck, I search the docs. |
| if the logs show errors | se os logs mostrarem erros | If the logs show errors, I investigate. |
| when you finish | quando você terminar | When you finish, send me the link. |
| if the build is slow | se o build estiver lento | If the build is slow, we use a cache. |

|-------|-------------------------|---------|
