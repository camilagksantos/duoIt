# Conteúdo: 5.12 Futuro para planos

Status: rascunho para revisão. Ainda não foi carregado no banco.

Regras usadas:
- Cada palavra aparece em um só grupo.
- As frases usam presente, passado e futuro (will e going to), além das estruturas dos módulos anteriores.
- Não usar present perfect (5.4), voz passiva (5.6) nem modais além de "will" e "going to".

## Grupo A: Decisões na hora e promessas

| Termo | Significado no contexto | Exemplo |
|-------|-------------------------|---------|
| will | vai (decisão na hora) | I will send the report by Monday. |
| I'll | eu vou | I'll check the logs now. |
| we'll | nós vamos | We'll deploy after the review. |
| you'll | você vai | You'll like the new layout. |
| they'll | eles vão | They'll answer soon. |
| won't | não vai | I won't push to production today. |
| it'll | vai | It'll be fine. |
| that'll be | isso vai ser | That'll be enough. |
| will be ready | vai estar pronto | The docs will be ready on Monday. |
| it will work | vai funcionar | It will work after the restart. |
| will probably | provavelmente vai | It will probably take a day. |
| I'll help | eu vou ajudar | I'll help you with the tests. |
| I'll reply | eu respondo | I'll reply to the email tonight. |
| I'll do it | eu faço | I'll do it after lunch. |
| I'll fix it | eu corrijo | I'll fix it this afternoon. |
| I'll send it | eu envio | I'll send it to you later. |
| I'll let them know | eu aviso eles | I'll let them know about the change. |
| I'll let you know | eu aviso você | I'll let you know when it's done. |
| I'll get back to you | eu retorno para você | I'll get back to you tomorrow. |
| I'll handle it | eu cuido disso | No worries, I'll handle it. |
| I'll take it | eu fico com isso | They'll send it over, I'll take it. |
| we'll see | veremos | We'll see what happens. |
| I will | eu vou (forma formal) | I will update you on the progress tomorrow. |
